# Asset Requirements

## Required Assets

### App Icon
- **File**: `./assets/icon.png`
- **Size**: 1024x1024 pixels
- **Format**: PNG with transparency
- **Design**: Clean, professional icon representing growth and healing
- **Colors**: Use app's primary color (#6CA0FF) or neutral tones
- **Style**: Modern, minimalist design that works at small sizes

### Adaptive Icon (Android)
- **File**: `./assets/adaptive-icon.png`
- **Size**: 1024x1024 pixels
- **Format**: PNG with transparency
- **Design**: Same as app icon but optimized for Android's adaptive icon system
- **Safe Zone**: Keep important elements within 66% of the icon (center area)
- **Background**: Will be filled with app's primary color

### Splash Screen
- **File**: `./assets/splash-icon.png`
- **Size**: 1284x2778 pixels (iPhone 14 Pro Max resolution)
- **Format**: PNG
- **Design**: App logo centered on dark background (#0E1116)
- **Content**: Simple, clean logo without text
- **Style**: Consistent with app's design language

### Favicon
- **File**: `./assets/favicon.png`
- **Size**: 48x48 pixels
- **Format**: PNG
- **Design**: Simplified version of app icon
- **Usage**: Web version of the app

## Design Guidelines

### Color Palette
- **Primary**: #6CA0FF (Blue)
- **Background**: #0E1116 (Dark)
- **Text**: #E6EAF2 (Light)
- **Accent**: #5ED3A8 (Green)

### Style Requirements
- **Minimalist**: Clean, uncluttered design
- **Professional**: Suitable for app store
- **Scalable**: Works at all required sizes
- **Accessible**: High contrast, clear shapes
- **Consistent**: Matches app's design language

### Icon Concepts
- **Growth/Healing**: Plant, butterfly, or upward arrow
- **Boundaries**: Shield, circle, or protective symbol
- **Journey**: Path, steps, or progress indicator
- **Privacy**: Lock, key, or secure symbol
- **Abstract**: Geometric shapes or modern patterns

- **High contrast** for visibility
